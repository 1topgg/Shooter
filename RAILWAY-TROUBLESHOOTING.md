## ❌ Проблема 1: Кнопка "Почати гру" не працює

### Симптоми:
- Кнопка заблокована/напівпрозора
- Текст "Підключення до сервера..."
- Статус "Підключення..." або "Відключено"

### Причина:
WebSocket не підключається до сервера

### Рішення:
Дивіться секцію "WebSocket не підключається" нижче

---

## ❌ Проблема 2: Гра працює "за екраном"

### Симптоми:
- Натиснули "Почати гру"
- Екран не змінюється, overlay залишається
- Персонаж помирає через 20-30 секунд
- У консолі пише "Game started"

### Причина:
Overlay не ховається через проблему з CSS або кешування браузера

### Рішення:

**✅ Виправлено в останній версії!**

Якщо ви досі бачите цю проблему:

1. **Жорстке оновлення браузера:**
   - Windows/Linux: `Ctrl + Shift + R` або `Ctrl + F5`
   - Mac: `Cmd + Shift + R`

2. **Очистити кеш повністю:**
   - Chrome/Edge: F12 → Network → "Disable cache" (галочка) → Ctrl+Shift+R
   - Firefox: F12 → Network → "Disable cache" (галочка) → Ctrl+Shift+R

3. **Режим інкогніто:**
   - Відкрийте Railway URL в режимі інкогніто (Ctrl+Shift+N)
   - Якщо працює - проблема в кеші

4. **Перевірте що код оновлено:**
   - Railway → Deployments → перевірте що останній деплой успішний
   - Час деплою має бути новіший ніж ваші зміни

5. **Примусове оновлення через консоль:**
   - F12 → Console
   - Виконайте: `location.reload(true)`

## ⚡ WebSocket не підключається

**Симптоми:**
- Кнопка "Почати гру" напівпрозора та заблокована
- Напис "Підключення до сервера..." замість "Почати гру"
- У правому верхньому куті статус "Підключення..." або "Відключено"

**Рішення:**

**A. Перевірте статус сервера на Railway:**
1. Увійдіть на https://railway.app
2. Відкрийте ваш проект
3. Перевірте:
   - ✅ Зелений статус "Active"
   - ✅ Логи без помилок (вкладка "Deployments" → клік на деплой → "View Logs")
   - ✅ URL доступний (клік на ваш домен)

**B. Перевірте налаштування Railway:**
1. У проекті натисніть на сервіс
2. Перейдіть в "Settings"
3. **ВАЖЛИВО - Перевірте порт:**
   - Railway автоматично виставляє змінну `PORT`
   - Ваш код в `server.js` використовує `process.env.PORT || 3000`
4. **Перевірте домен:**
   - В розділі "Networking" має бути згенерований домен типу `your-app.up.railway.app`

**C. Примусове оновлення браузера:**

Railway може бути підключений, але браузер кешує старі файли.

**ОБОВ'ЯЗКОВО зробіть жорстке оновлення:**
- **Windows/Linux**: `Ctrl + Shift + R` або `Ctrl + F5`
- **Mac**: `Cmd + Shift + R`

**АБО:**
1. Відкрийте Developer Tools (F12)
2. Правий клік на кнопку оновлення → "Очистити кеш та жорстко перезавантажити"
3. АБО в Network tab поставте галочку "Disable cache"

**D. Перевірте консоль браузера:**
1. Натисніть F12 (Developer Tools)
2. Перейдіть на вкладку "Console"
3. Шукайте повідомлення:
   ```
   Game initialization starting...
   Elements check: {canvas: true, startBtn: true, ...}
   Setting up start button listener
   WebSocket error: ...
   ```
4. Якщо бачите помилку WebSocket - це проблема з підключенням до Railway

#### 2. 🌐 CORS або змішаний контент (Mixed Content)

**Симптоми:**
- Помилка в консолі: "Mixed Content" або "blocked by CORS"
- WebSocket не може підключитися

**Рішення:**

**Railway використовує HTTPS за замовчуванням**

Переконайтеся що:
1. Відкриваєте сайт через HTTPS (не HTTP)
2. WebSocket підключається через WSS (не WS)

Код автоматично визначає протокол:
```javascript
const protocol = window.location.protocol === 'https:' ? 'wss:' : 'ws:';
```

Якщо відкриваєте через `http://your-app.up.railway.app`, змініть на `https://your-app.up.railway.app`

#### 3. 🔄 Railway не запустився після деплою

**Симптоми:**
- Сайт не відкривається взагалі
- Або показує "Application Failed"

**Рішення:**

**A. Перевірте Procfile:**
Файл `Procfile` в корені проекту має містити:
```
web: node server.js
```

**B. Перевірте package.json:**
```json
{
  "scripts": {
    "start": "node server.js"
  },
  "engines": {
    "node": ">=18.0.0"
  }
}
```

**C. Подивіться логи Railway:**
1. Railway → ваш проект → Deployments
2. Клікніть на останній деплой
3. Клікніть "View Logs"
4. Шукайте помилки типу:
   - `Error: Cannot find module 'express'` → запустіть Build Command
   - `Port already in use` → Railway автоматично виправить

#### 4. ⏳ Часова затримка підключення

**Симптоми:**
- Кнопка заблокована 5-10 секунд після завантаження сторінки
- Потім розблоковується автоматично

**Це нормально!** Railway може мати холодний старт (cold start) якщо сервер був неактивний.

**Рішення:** Просто зачекайте 10-15 секунд після відкриття сторінки.

```javascript
}
```
